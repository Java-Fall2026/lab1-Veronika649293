# Звіт про використання інструментів AI

# 1. Запит до AI 
"як правильно реалізувати валідацію дат і переліків String у допоміжному класі ShelterUtils, створити правильні equals/hashCode для складеного ключа CareSchedule та написати обчислювальний метод careDays для Java 21"

# 2. Що AI запропонував неправильно або не за вимогами завдання:
- Використання Enum: AI запропонував створити окремі файли `enum` для полів `diet` та `health`, що суперечить вимогам ТЗ, які вимагають використання звичайного рядка `String` з нормалізацією до UPPERCASE.
- Очікуваний формат помилок: У повідомленнях винятків `IllegalArgumentException` AI спочатку не додав вивід поточного та очікуваного значень (наприклад, просто виводив *"Invalid diet"* замість *"Diet must be one of [CARNIVORE, HERBIVORE, OMNIVORE], got: 'FAST_FOOD'"*).
- Обчислення тривалості опіки: У методі `careDays` AI не врахував випадок, коли `endDate == null` (коли опіка ще триває), і намагався викликати метод `between`, що призводило до помилки `NullPointerException`.

# 3. Що було перевірено та виправлено самостійно:
- Відхилено використання `enum` та реалізовано нормалізацію рядків через `FormatHelper.normalizeUpper()` і перевірку на належність до `List.of(...)`.
- Допрацьовано шаблони помилок у `ValidationHelper` так, щоб вони чітко пояснювали причину і виводили отримані значення.
- Додано перевірку на `null` для `endDate` у методі `careDays(CareSchedule)` із поверненням значення `-1` відповідно до умов доменного профілю Варіанту 18.
- Перевірено та налаштовано модифікатори доступу (`package-private` для допоміжних класів валідації та `public` для `ShelterUtils`).
